**根本原因**：
1. 携程爬取时城市分配就错位了
2. 高德 API 对部分景点返回了错误坐标（如"外滩"返回洛阳坐标）
3. "坐标最近城市中心"算法不适合中国行政区划（千岛湖属杭州但地理靠近黄山）

**正确修复方案**：
- 不要用坐标反推城市，而是用**景点名关键词**推断城市（更可靠）
- 对坐标明显偏离城市的景点，**重新调用高德 API** 用更精确的地址获取
- 千岛湖系列景点应保留为杭州（行政归属）
- 大理系列景点应保留为大理

## 六、技术栈

- **后端**：Django 5.x + MySQL
- **前端**：Tailwind CSS + 高德地图 JS API v2.0
- **AI**：LangGraph + DeepSeek（OpenAI 兼容接口）
- **地图**：高德地图 Web 服务 API（地理编码/路径规划）
- **爬虫**：browser-harness（CDP 控制真实 Chrome）
- **图片**：携程 CDN + Django Template Filter 动态转高清
